# ui

The management UI (specification chapter 10; RFC 017): Svelte 5 + TypeScript, two language
catalogues (`src/lib/i18n/en.json`, `ja.json`), the word check (`scripts/wordcheck.mjs`), the
size check (`scripts/size.mjs`). Built into `dist/`, which `enkrnettd --ui-dir` serves.

Internal design: `docs/src/design/ui.md`. Build and test: `docs/src/contributors/building-and-testing.md`.
