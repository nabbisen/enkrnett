# Erase

Erase removes everything you set up: the guest Wi-Fi, the management Wi-Fi, the owner password,
and the country. The device returns to how it was right after installation and offers its setup
Wi-Fi again, as if new. Use it to start over, to hand the device to someone else, or when the
owner password is lost. It takes about two minutes.

Erase does not remove Enkrnett itself and does not bring back the router's original firmware.

## From the settings screen

1. Open the menu, *Settings*, and at the bottom *Erase this device…*.
2. Read what the screen says it removes. Enter the owner password.
3. Press *Erase this device*. The screen says the device restarts and opens its setup Wi-Fi in
   about two minutes.

## With the button

When you cannot log in, for example because the owner password is lost:

1. Find the small button on the back of the device. It is recessed; a pen tip reaches it.
2. **Hold it for five seconds, until the light changes.** A shorter press only restarts the device
   and changes nothing.
3. Let go. The device restarts; within about two minutes the light is steady and the setup Wi-Fi
   `Enkrnett Setup` followed by the label's four characters is back.

## Afterwards

- Phones that knew the management Wi-Fi can no longer join it. Your guests' phones find no guest
  Wi-Fi until you set up again.
- Set up again with [Set up](./set-up.md). You may use the same names; the device makes a new
  management Wi-Fi password and you choose the owner password again.
- Nothing you set up is kept anywhere else: the device alone held it, and it is gone.

## Restart is not Erase

*Restart* (menu, *Details*) turns the device off and on. The Wi-Fi stops for about a minute and
**nothing changes**. A short press of the small button does the same. Use Restart when the device
seems stuck; use Erase only to start over.
