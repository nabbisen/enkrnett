# 0.1.0

Tagged 2026-11-26 on the owner's authorization at the M1 stage 5 commit (`f089392`). Milestone
M1, *Skeleton*: daemon and management UI together on the virtual machine; a device can be
claimed and reset. For development and testing; not for operators (ROADMAP, release cycle). The
Tier 1 device part of the M1 exit condition was open at the tag and carries into M3. These notes
were written after the tagged commit, on `main`; the tagged tree does not contain them.

## What it contains

| Area | Content | Chapter |
|---|---|---|
| Workspace | `enkrnett-model`, `enkrnett-ubus`, `enkrnettd` (RFC 013 §5) | 13 |
| Management API | Every resource against a mock platform and against OpenWrt; HTTP/1.1 with the limits and headers of chapter 9; ownership state machine; sessions in memory; argon2id; login delay; persistence with format version; Erase | 3, 4, 9 |
| Management UI | Every screen of chapter 10 in English and Japanese; catalogues as JSON; the word check and the size check in the build | 10 |
| OpenWrt platform | UCI files written by the daemon's own user by temp-and-rename; ubus reload and events; health check by SSID; readings; hardening report; erase marker; reboot; profile selection by board name | 6, 7 |
| Package | `procd` service as user `enkrnett` with no capability; `ubusd` ACL; first-boot script; `boot()` acts on the erase marker; LED attribute hand-over; profiles for ELECOM WRC-1167GST2 and Buffalo WCR-1166DS | 13 |
| Build | The daemon for `mipsel_24kc` from the pinned SDK toolchain and `nightly-2026-11-21`; `std` built for size; the budgets of chapter 8 enforced; pinned inputs with checksums in `openwrt/lock` | 8, 13 |
| Carried patch | `openwrt/patches/0001-…`: the wifi-scripts Transition Mode BSSID fix (ENK-REPO-002) | 13 |

## How it was verified

`docs/src/verification/m1.md` has the record. In short:

| Where | What |
|---|---|
| CI, every commit | Model, ubus codec, and daemon unit tests; the API contract tests over TCP; the UI word check, types, unit tests, build and size; the browser harness, 14 tests at phone size on Chromium and WebKit against the mock daemon; the MIPS build and budgets; the package in the SDK |
| The x86-64 OpenWrt VM | `tests/vm/package.sh` (install through `apk`, start by `procd`) and `tests/vm/contract.sh`: 51 checks of RFC 003 and RFC 004 against the real platform, including Erase through a real boot; every one passed on 2026-11-26 |
